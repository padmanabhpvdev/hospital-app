# Hospital Appointment App using ReactJS
Realtime Hospital Appointment App using NodeJS and ReactJS

## How to use ?
First, set the requirements :
> ReactJS
> NodeJS

Clone or download the hospital app using following code:
```git
git clone https://github.com/padmanabhpvdev/hospital-app.git
```
After successful installation, head to the location :
```bash
cd hospital-app
```
Install necessary packages :
```bash
npm i
```
Run the app using following code:
```bash
npm run dev
```
> [!NOTE]
> You also need to run nodejs for backend functionality.You need to open another terminal on same location and run the following code:
> ```bash
> cd backend
> node server.js
> ```
